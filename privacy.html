Privacy Policy

mail-assistant is a personal tool used by a single person (its owner) to access the owner's own Gmail accounts.

What data is accessed

With the owner's consent, the app reads email messages and attachments using the read-only Gmail scope (https://www.googleapis.com/auth/gmail.readonly). It cannot send, delete or modify email.

How data is used

Email content is used only to show the owner verification codes, search results and documents from their own mailboxes, delivered to the owner's private Telegram chat. Message text may be processed by the Anthropic Claude API solely to extract codes and answer the owner's questions.

Storage and sharing

Data is stored only on a server controlled by the owner. It is not sold, not shared with third parties (other than the processing described above), and not used for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
